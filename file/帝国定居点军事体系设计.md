# 定居点军事体系设计

## 1. 兵种等级与定位

### T1–T3：民兵 / 志愿兵
- 定位：基础兵员、炮灰。
- 用途：守城、维护治安、承担基础战斗消耗。
- 不属于军区兵。
- 无军营也可以招募或生成。

### T3–T4：军区兵
- 定位：正规地域军事力量。
- 主要兵种：中装步兵、中装射手、中装骑兵。
- 兵员生成与补充由定居点**军营**决定。
- 升级速度由**训练场**控制。
- 由 **Fief Party** 体系使用和维持。

### T4–T6：职业兵
- 定位：高质量正规职业军与精锐。
- 主要兵种：重装步兵、高级射手/弩兵、具装骑兵。
- 兵员生成与补充由定居点**军营**决定。
- 升级速度由**训练场**控制。
- 主要用于 **Garrison（驻军）和领主军队**。
- 不建立独立的驻军兵种树，驻军直接使用职业兵种。

## 2. 定居点建筑

### 军营
军营负责决定定居点能够生成和补充哪些**军区兵与职业兵**。

- 军营等级决定可生成兵种的等级和种类。
- 军区兵和职业兵均受军营限制。
- T1–T3 民兵 / 志愿兵不依赖军营。
- 核心职责：**决定“能产生什么兵”。**

### 训练场
训练场不负责解锁或生成兵种，只负责提高士兵升级速度。

- 加速军区兵升级。
- 加速职业兵升级。
- 核心职责：**决定“士兵成长多快”。**

## 3. 定居点兵力结构

```text
定居点
│
├── 民兵 / 志愿兵 T1–T3
│     ├── 无需军营
│     └── 守城 / 治安 / 基础兵员
│
├── 军营
│     ├── 军区兵 T3–T4
│     │     └── Fief Party
│     │
│     └── 职业兵 T4–T6
│           └── Garrison / 领主军队
│
└── 训练场
      └── 加速军区兵与职业兵升级
```

## 4. 体系边界

| 等级 | 体系 | 主要装备与定位 | 是否需要军营 | 主要用途 |
|---|---|---|---|---|
| T1–T3 | 民兵 / 志愿兵 | 轻装、基础兵员、炮灰 | 否 | 守城、治安、基础兵员 |
| T3–T4 | 军区兵 | 中装步兵 / 射手 / 骑兵 | 是 | Fief Party |
| T4–T6 | 职业兵 | 重装步兵 / 高级射手 / 具装骑兵 | 是 | Garrison、领主军队 |

## 5. 核心原则

> 民兵 / 志愿兵负责数量、基础守备和治安；军区兵承担地域军事义务；职业兵负责高质量军事力量。

> **军营决定“能产生什么兵”，训练场决定“这些兵成长多快”。**

> **Fief Party 使用军区兵；Garrison 不建立独立兵种树，直接使用职业兵。**
