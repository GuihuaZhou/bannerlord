# Bannerlord 附庸国与傀儡国外交规则

## 1. 核心定义

-   **附庸国（Vassal）**：外交自主，但宗主义务优先。
-   **傀儡国（Puppet）**：军事外交受宗主控制，经济外交自主。

## 2. 建立时的外交关系清理

  -----------------------------------------------------------------------------------------------
  外交关系                附庸国                               傀儡国
  ----------------------- ------------------------------------ ----------------------------------
  战争 / 和平             加入宗主当前战争；自身已有战争保留   战争 / 和平全部同步宗主

  同盟                    原则上保留；与宗主敌国的同盟解除     原有同盟全部解除

  贸易协定                原则上保留；与宗主敌国的贸易解除     原则上保留；与宗主敌国的贸易解除
  -----------------------------------------------------------------------------------------------

## 3. 发生在附庸国 / 傀儡国上的外交事件

### 附庸国

-   **宣战**：允许，不要求宗主参战。
-   **求和**：允许，但不能退出宗主正在进行的战争。
-   **结盟**：允许，但不能与宗主当前敌国结盟。
-   **贸易协定**：允许，但不能与宗主当前敌国贸易。

### 傀儡国

-   **宣战**：禁止。
-   **求和**：禁止。
-   **结盟**：禁止。
-   **贸易协定**：允许，但不能与宗主当前敌国贸易。

## 4. 发生在宗主国上的外交事件

### 宗主宣战

-   **附庸国**：必须加入战争。
-   **傀儡国**：自动同步为战争状态。

### 宗主求和

-   **附庸国**：必须跟随宗主结束该战争。
-   **傀儡国**：自动同步为和平状态。

### 宗主结盟

-   不要求附庸国同步。
-   不要求傀儡国同步。

### 宗主签订贸易协定

-   不要求附庸国同步。
-   不要求傀儡国同步。

## 5. 总结

``` text
附庸国
= 外交自主
+ 宗主义务优先

傀儡国
= 军事外交受控
+ 经济外交自主
```
