# Bannerlord 本体王国外交评分与决议机制

## 1. 两层结构

Bannerlord 的王国外交不是使用一个固定分数直接决定结果，而是分为两层：

1. `DiplomacyModel` 计算战争或和平的价值。
2. `KingdomDecision` 让王国内各个非雇佣 Clan 分别选择结果，再由 `KingdomElection` 汇总支持、影响力与统治者选择。

因此需要区分：

- 外交价值分；
- Clan 对某个决议结果的支持度；
- 王国决议的最终通过概率。

## 2. 宣战评分

`DefaultDiplomacyModel.GetScoreOfDeclaringWar` 综合收益、风险、接壤程度、文化领土、关系与同盟因素。王国实力低于 500 或不足两支战争部队时，直接返回极低分。

`DeclareWarDecision.DetermineSupport` 为每个 Clan 计算：

```text
支持开战 = 开战价值 + 勇武 × 20 - 仁慈 × 10
反对开战 = -支持开战
```

因此单个 Clan 的倾向分界线是 `0`：

- 大于 0：倾向开战；
- 小于 0：倾向反对；
- 等于 0：没有明确偏好。

决议系统随后根据偏好强度、Clan 影响力、提案成功概率以及与提案 Clan 的关系，将支持转换为三档投入：

```text
轻度支持：基础影响力成本 20
强烈支持：基础影响力成本 60
全力推动：基础影响力成本 150
```

## 3. 和平评分

`DefaultDiplomacyModel.GetScoreOfDeclaringPeace` 综合以下因素：

- 双方实力与多线战争压力；
- 战争收益和风险；
- 战争持续时间；
- 伤亡；
- 城镇、城堡围攻成果；
- 村庄劫掠；
- 文化领土与 Clan 关系。

王国和平门槛为：

```text
GetDecisionMakingThreshold = 王国定居点总价值 / 6
```

AI 主动提出和平通常要求：

- `IsPeaceSuitable` 为 true；
- 王国和平分数达到动态门槛；
- 赔款方向允许发起提案；
- 提案 Clan 自己支持和平。

## 4. 和平决议中的 Clan 支持

`MakePeaceKingdomDecision.DetermineSupport` 不直接把连续和平分数返回给选举，而是主要转换为两档：

```text
支持该结果：200
不支持该结果：0
```

Clan 支持和平通常要求王国和平分数超过动态门槛，并且该 Clan 的和平分数高于调整后的王国和平分数。收到赔款时条件会更宽松。

Clan 反对和平通常发生在王国和平分数没有达到门槛，或该 Clan 自己的和平分数不足时。

## 5. 对宗藩决议的启示

附庸或傀儡协议应复用相同思路：

1. 先计算每个 Clan 的连续臣服意愿，用于解释战争潜力、战争倾向、战争局势、主权损失和贡赋负担。
2. 再把连续分数转换为 `接受=200/0` 与 `拒绝=0/200`。
3. 最终交给正式的 `KingdomDecision` 与 `KingdomElection` 汇总，而不是由两个统治者直接比较一个总分。

和平与臣服必须使用不同门槛。国家受到严重打击时可以接受和平或赔款；只有危机进一步恶化时，Clan 才可能支持附庸或傀儡协议。

## 7. 当前宗藩协议的 Clan 计算框架

当前实现先以观察模式运行，玩家提出的有效协议仍然会成功，但日志中的预测已经改为 Clan 逐票计算。

对方被要求成为附庸或傀儡时，每个非雇佣 Clan 分别考虑：

- 附庸或傀儡造成的主权损失，傀儡的基础代价更高；
- 双方军事实力，但和平时期的实力威慑设有较低上限；
- 本体 `GetWarProgressScore` 提供的伤亡、攻城和劫掠战果；
- Clan 自身的战争潜力；
- Clan 自身的战争倾向；
- 王国剩余城镇和城堡数量，该项是连续修正而非硬性门槛；
- Clan 按实际领地需要承担的每日贡赋；
- 统治 Clan 额外承担的主权阻力。

每个 Clan 的连续意愿以 `0` 为分界线，再转换为：

```text
愿意接受：接受支持度 200，拒绝支持度 0
不愿接受：接受支持度 0，拒绝支持度 200
```

和平时期，单纯因为另一王国强大、己方定居点较少，不足以接受臣服。只有战争失败、战争潜力枯竭、明显厌战和领土危机等因素叠加，才可能抵消主权损失。

主动臣服需要经过双边评估：臣服国各 Clan 先判断是否愿意放弃主权，接收国各 Clan 再判断是否愿意接纳该臣属国。接收方会权衡新增领土与力量，以及是否同时继承战争义务。未来建立正式 `KingdomDecision` 时，可以直接复用相同的 Clan 结果对象和 200/0 支持度。

臣服国的生存危机不能只看拟议宗主。计算会扫描其全部现役战争：

- 如果拟议宗主本身正在攻击臣服国，双方战争进展作为直接投降压力；
- 对其他敌国，选取战争进展和相对实力造成压力最大的国家；
- 同时作战的敌国越多，多线战争压力越高；
- 拟议宗主相对最大外部敌人的实力决定其保护能力；
- 直接战争与外部敌国压力分开计算，同一敌国不会重复计分。

敌国实力只会放大已经发生的战争劣势，不能单独触发臣服。战争刚刚开始且尚无实际损失时，即使敌人远强于臣服国，也不会凭空获得外部危机分。宗主保护能力同样会随实际危机程度逐步生效。

因此，一个正在被北帝国重创的南帝国，即使与玩家和平，也可能因为整体生存危机而愿意投靠玩家；但如果玩家远弱于北帝国，宗主保护能力会产生负修正。
