# 斯特吉亚军事体系设计

斯特吉亚以**罗斯诸公国---莫斯科大公国**为原型，特点是**集权较低、步兵传统强，依靠自由民征召、土地服役阶层和王公亲兵**。

## 1. 兵源划分

  -----------------------------------------------------------------------
  系统                                兵种
  ----------------------------------- -----------------------------------
  **志愿兵**                          T1--T3 普通盾步兵、猎人/射手、散兵

  **Fief Party**                      T4--T5 重矛盾兵、重斧盾兵、Horse
                                      Raider、Varyag Veteran → Druzhinnik

  **职业兵**                          T4--T5 正规重装弓兵、Line Breaker →
                                      Ulfhednar

  **特殊精锐**                        Druzhinnik Champion T6

  **地方民兵**                        保留现有民兵
  -----------------------------------------------------------------------

Fief Party
代表**土地服役体系**：土地收益供养服役贵族及武装随从，战争时承担军役，因此不按普通职业军支付工资。

## 2. 军营控制

-   **无军营**：无职业兵。
-   **军营 I**：解锁 T4--T5 正规重装弓兵。
-   **军营 II**：解锁 T4--T5 Line Breaker / Ulfhednar。
-   **军营 III**：参与解锁 T6 Druzhinnik Champion，并附加王公/Clan
    等身份条件。

T4--T5 Druzhina 主要通过 **Fief Party** 获得，T6
则作为王公最高级亲兵严格限制数量。

## 3. 核心特色

> **志愿兵提供普通步兵；土地服役体系提供重装步兵、骑马战士和
> Druzhina；军营提供少量专业步射兵；最高级 Druzhina 属于王公核心亲卫。**

因此斯特吉亚的高级军事力量主要依附于**土地和贵族军役体系**，而不是庞大的中央常备职业军。
