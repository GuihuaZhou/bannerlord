# 战争潜力与战争倾向系统修订设计

> 状态：设计共识，尚未修改代码。
> 
> 范围：仅整理已确认内容，不包含暂缓讨论的宣战冷却机制。

## 一、核心定位

系统分为两个相互独立的维度：

| 系统 | 属性 | 核心问题 |
|---|---|---|
| WarPotential（战争潜力） | 客观 | Clan 能不能继续打？ |
| WarDisposition（战争倾向） | 主观 | Clan 想不想继续打？ |

**战争潜力**由实际野战兵力、驻军与封邑兵源、可用统兵 Hero、财政持续能力决定，保持现有设计。

**战争倾向**由 Clan Leader 的人格特质、战争持续时间和实际战争事件共同决定，范围为 `[-100, 100]`。

战争潜力不直接改变战争倾向，战争倾向也不直接改变战争潜力。

## 二、战争倾向人格基准（Baseline）

每个 Clan 拥有一个由现任 Leader Trait 决定的动态人格基准：

```text
Baseline = Clamp(12 × Valor − 15 × Mercy − 3 × Generosity, -40, 40)
```

其中：

- `Valor`：勇武为正，胆怯为负。
- `Mercy`：仁慈为正，残忍为负。
- `Generosity`：慷慨为正，吝啬为负。
- `Honor`、`Calculating` 等特质继续影响具体战争事件，不直接参与 Baseline。

示例：

| Leader 特质 | Baseline |
|---|---:|
| 勇武 +2、残忍 -2 | +40 |
| 勇武 +1、仁慈 +1 | -3 |
| 胆怯 -1、仁慈 +2 | -40 |
| 无相关特质 | 0 |

Baseline 每次计算时读取现任 Clan Leader 的 Trait，不单独持久化。更换 Leader 或 Trait 变化后，Baseline 自动更新。

Baseline 只是长期人格倾向，不限制实际 WarDisposition 的变化范围。

## 三、战争期间：逐渐厌战

处于正式王国战争时，每日向 `-100` 趋近，采用固定比例：

```text
WarDisposition_new = WarDisposition_old + (-100 − WarDisposition_old) × 0.01
```

即每日向 -100 缩小剩余差距的 1%。

特征：

- 战争越久，厌战情绪越明显。
- 趋近 -100 的速度逐渐放缓。
- 持续胜利和战争收益能够抵消厌战压力。
- 不因达到特定战争天数而强制结束战争。

从 0 开始、不考虑其他事件时：

| 战争持续 | 战争倾向 |
|---|---:|
| 30 天 | -26 |
| 90 天 | -60 |
| 180 天 | -84 |
| 300 天 | -95 |

## 四、和平期间：逐渐恢复人格基准

结束全部正式王国战争后，Clan 进入和平恢复状态。

```text
WarDisposition_new = WarDisposition_old + (Baseline − WarDisposition_old) × RecoveryRate
```

和平恢复比例随和平持续时间线性递增，达到上限后不再增长：

```text
RecoveryRate = Min(0.005 + 0.002 × PeaceDays, 0.06)
```

`PeaceDays` 为已经度过的完整和平天数，和平首日为 0。

| 和平时间 | 每日恢复比例 |
|---|---:|
| 第 1 天 | 0.5% |
| 第 5 天 | 1.3% |
| 第 10 天 | 2.3% |
| 第 15 天 | 3.3% |
| 第 20 天 | 4.3% |
| 第 25 天 | 5.3% |
| 第 29 天及以后 | 6.0% |

恢复初期缓慢，为 Clan 提供补兵、整军和恢复战争潜力的时间；随后逐渐加快，最终恢复到自身人格基准。

当实际倾向与 Baseline 的差距不超过 1 点时，直接归位，避免浮点数长期无法到达目标。

例如停战时 `WarDisposition = -80`、`Baseline = +40`：

| 和平持续 | 战争倾向（约） |
|---|---:|
| 10 天 | -64 |
| 20 天 | -34 |
| 25 天 | -17 |
| 30 天 | -3 |
| 40 天 | +17 |

因此，好战领主也不会在停战后立即恢复强烈主战意愿。

## 五、战争事件

保留现有事件体系及 Trait 反应权重。

| 事件 | 基础影响 |
|---|---:|
| Party 胜利 | +3 |
| Party 战败 | -3 |
| Party 被摧毁 | -6 |
| 成员被俘 | -3 |
| 成员战死 | -4 |
| 成员被处决 | -10 |
| 村庄被劫掠 | -3 |
| 城堡失守 | -6 |
| 城镇失守 | -8 |
| 俘虏敌方 Hero | +2 |
| 攻占城堡 | +4 |
| 攻占城镇 | +5 |
| 获封城堡 | +10 |
| 获封城镇 | +15 |

事件变化继续使用：

```text
ΔWarDisposition = EventBaseValue × ClanRelationMultiplier × PersonalityModifier
```

本 Clan 事件按 100% 计算，同王国其他 Clan 的事件按 20% 传播。

人物特质仍按不同事件使用不同反应权重。战争胜负、伤亡及领土收益可以使实际战争倾向明显偏离人格 Baseline。

### 移除每周财富事件

彻底取消每周财富变化对 WarDisposition 的影响。

Clan 财政状况已经由 WarPotential 的财政持续能力体现，避免重复计算。

## 六、和平时间记录

当前 Mod 已能获取战争持续时间，但尚未持久化每个 Clan 的和平起始时间。

新增 `PeaceStartTime`，规则如下：

1. 存在至少一场正式王国战争时，使用战时计算，和平计时重置。
2. 全部正式王国战争结束时，记录和平开始时间。
3. 和平期间按已持续天数计算递增恢复比例。
4. 再次进入战争时，结束和平计时；下一轮和平重新从 0 天开始。

多场战争并存时，只有全部结束才进入和平恢复。

旧存档缺少和平起始时间时，从首次确认和平状态的时间开始记录，不猜测历史和平天数。

## 七、政治决议

暂时保留现有决议评分机制：

```text
最终支持度 = 本体支持度 + 战争倾向修正
```

倾向为负时提高和平支持度、降低继续战争支持度；倾向为正时反向处理。

自定义 WarPotential 暂不新增到普通和平、宣战决议中，相关客观战争能力与本体外交评分的整合另行讨论。

不增加强制停战、最低和平期限或主动宣战冷却机制。

## 九、最终设计目标

建立如下动态循环：

```text
战争开始
  → 实际胜败影响意愿
  → 长期战争积累厌战
  → 停战
  → 初期缓慢恢复意愿并整军
  → 随和平持续逐渐恢复人格基准
  → 重新依据战争形势决定是否开战
```

最终达到：

- 能打，不代表想打。
- 想打，不代表能打。
- 长期战争自然产生结束战争的动力。
- 持续胜利能够维持战争意愿。
- 和平之后留有恢复军力的窗口。
- 不同性格的领主具有不同的长期战争态度。
