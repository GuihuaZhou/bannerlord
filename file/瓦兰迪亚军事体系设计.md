# 瓦兰迪亚军事体系设计

瓦兰迪亚分为**志愿兵、北方封建兵、南方职业兵**三套兵源。北方军事传统逐渐演变为斯瓦迪亚，南方军事传统逐渐演变为罗多克。

## 1. 志愿兵

南北共同使用，不受军营控制。

-   T1--T3 普通步兵
-   T1--T3 普通弩兵
-   现有长枪兵保持不变，不承担特色兵种定位

定位：廉价、大量的基础兵员。

## 2. 北方封建兵

特点：**步射较弱，骑兵和贵族骑士强。**

-   **新增弱封建军士**：实力低于南方职业军士
-   **新增弱封建弩手**：实力低于南方职业弩手
-   普通骑兵：`Light Cavalry → Cavalry → Vanguard`
-   贵族骑士：`Gallant → Knight → Champion`
-   T6 `Banner Knight`：最高级贵族骑士

取消 `Champion T5 → Banner Knight T6`。

T6 Banner Knight **不能通过升级获得，只能由三级军营生成**。

## 3. 南方职业兵

特点：**没有北方的骑兵优势，但拥有更强的精锐步兵和弩兵。**

-   **强职业军士**：重装剑盾步兵
-   **钩镰军士**：重装长柄职业步兵
-   **强职业弩手**：重装专业弩兵

南方军士、弩手质量均高于北方对应封建兵。

## 4. 军营控制

军营控制**兵种生成权限**，而不是简单限制 Tier。

  军营等级       北方                        南方
  -------------- --------------------------- ---------------
  **无军营**     普通骑兵、T3--T5 贵族骑士   无职业兵
  **一级军营**   \+ 弱封建军士               \+ 强职业军士
  **二级军营**   \+ 弱封建弩手               \+ 强职业弩手
  **三级军营**   \+ T6 Banner Knight         \+ 钩镰军士

## 5. 最终军事特色

-   **北方：弱步射 + 强骑兵 + 顶级骑士 → 斯瓦迪亚传统。**
-   **南方：强军士 + 强钩镰军士 + 强弩兵 → 罗多克传统。**
