# 阿塞莱军事体系设计

阿塞莱分为**伊克塔兵**和**职业兵**两套主要军事来源。

## 1. 伊克塔兵

由伊克塔土地军役体系提供，**不受军营限制**：

-   T1--T3 炮灰步兵
-   T1--T3 炮灰射手
-   `Faris T4 → Veteran Faris T5 → Vanguard Faris T6`：标枪骑兵

定位：提供阿塞莱的基础兵力和地方骑兵。

## 2. 职业兵

由定居点军营提供：

-   普通重步兵
-   普通高级射手
-   `Mamluke Guard → Palace Guard`：马穆鲁克重步兵
-   **精英马穆鲁克枪骑兵 T4 → T5 → T6**

废弃的马穆鲁克骑射线继续保持废弃。

## 3. 军营控制

  军营等级       可生成兵种
  -------------- -----------------------------
  **无军营**     仅伊克塔兵
  **一级军营**   \+ 普通重步兵、普通高级射手
  **二级军营**   \+ 马穆鲁克重步兵
  **三级军营**   \+ 精英马穆鲁克枪骑兵

## 4. 最终特色

**伊克塔提供炮灰步射兵和 Faris
标枪骑兵；军营提供正规重装职业军；高级军营逐步解锁马穆鲁克精锐。**
