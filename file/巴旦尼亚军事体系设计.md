# 巴旦尼亚军事体系设计

巴旦尼亚特点是**集权低、氏族军事传统强、职业军规模有限**。氏族体系提供
Fian 精锐，军营主要负责高级步兵和散兵。

## 1. 兵源划分

  -----------------------------------------------------------------------
  系统                                兵种
  ----------------------------------- -----------------------------------
  **志愿兵**                          T1--T3 普通步兵、普通散兵

  **Fief Party / 氏族军**             Highborn Warrior T3 → Hero T4 →
                                      Fian T5 → Fian Champion T6

  **职业兵**                          Veteran Skirmisher T4 → Wildling
                                      T5；Falxman T4 → Veteran Falxman /
                                      Oathsworn T5

  **骑兵**                            原废弃骑兵线继续废弃

  **地方民兵**                        保留现有民兵
  -----------------------------------------------------------------------

Fief Party 代表**氏族军事体系**。Fian
属于氏族传统精锐，不受军营等级限制。

## 2. 军营控制

-   **无军营**：无高级职业步兵。
-   **军营 I**：解锁 T4--T5 高级散兵。
-   **军营 II**：解锁 Falxman → Veteran Falxman。
-   **军营 III**：解锁 Oathsworn 重甲盾步兵。

## 3. 核心特色

> **普通人口提供低阶步兵，氏族体系提供 Fian
> 精锐，军营提供高级散兵和重装步兵。**

巴旦尼亚最强远程精锐来自氏族传统；军营发展则提供更强的专业步兵。
