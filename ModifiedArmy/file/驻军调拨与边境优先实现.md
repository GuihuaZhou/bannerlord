# 驻军调拨与边境优先实现

## 1. 目标

驻军与领主部队交换士兵时，内地定居点降低驻军目标以释放野战兵力；与交战敌人直接接壤的边境定居点继续优先维持原版驻军规模。

## 2. 代码位置

| 文件 | 职责 |
|---|---|
| `ModifiedArmy/Garrison/Models/GarrisonTransferPolicyModel.cs` | 集中定义边境判定、驻军目标、可捐兵数量和驻军取兵规则 |
| `ModifiedArmy/Garrison/Patches/GarrisonTroopDonationPatch.cs` | 拦截原版驻军交换流程，调用 Model API，并记录玩家王国的取兵日志 |
| `ModifiedArmy/Recruitment` | 提供统一的编制、工资、长期维护费和兵种结构限制 |

## 3. 驻军目标

`GarrisonTransferPolicyModel.GetExchangeIdealGarrisonSize` 接收原版计算结果：

- 敌方边境要塞：保留原版目标的 100%；
- 其他城镇或城堡：使用原版目标的 40%；
- 原版流程中的 125/75 最低驻军约束保持不变。

40% 比例由 `InteriorIdealGarrisonRatio` 集中定义，补丁内不保存平衡参数。

## 4. 敌方边境判定

`IsEnemyBorderFortification` 只在以下条件全部满足时返回 true：

1. 当前定居点是城镇或城堡；
2. 当前所属势力是有效王国势力；
3. 原版要塞邻接关系中至少存在一个直接相邻的城镇或城堡；
4. 该相邻要塞所属势力与当前定居点所属势力正在交战。

仅仅“王国处于战争状态”不构成边境。敌人必须占有直接相邻的要塞，避免远离战线的内地城市继续囤积过量驻军。

## 5. 领主向驻军捐兵

`GetAllowedDonationCount` 根据以下条件计算领主部队可捐出的盈余：

- 部队人数上限；
- 工资支付上限；
- 当前粮食可维持的兵力；
- 部队至少保留 30 人。

补丁最终只把原版申请捐赠数量压缩到 Model 允许的范围内。

## 6. 领主从驻军取兵

`TransferApprovedTroopsFromGarrison` 将驻军兵种转换为统一招募候选，并调用现有招募 Model 生成计划。实际转移严格遵守计划批准的兵种和数量，因此同时接受：

- 当前编制上限；
- 当前工资限制；
- 长期维护能力；
- 兵种结构限制；
- 95% 人数阈值等统一招募规则。

伤兵数量随对应兵种精确转移。补丁跳过原版随机取兵循环，防止原版再次选中未被统一招募计划批准的高工资兵种。

## 7. 日志

只有玩家所在王国的 AI 部队实际从驻军取得士兵时，才输出 `[驻军调拨]` Notice 日志。日志数量通过驻军转移前后人数差计算，不会把失败申请记录成成功取兵。
