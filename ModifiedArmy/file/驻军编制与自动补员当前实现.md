# 驻军编制与自动补员当前实现

## 规则

- 敌对边境要塞：编制上限 95%，安全下限 75%。
- 内陆要塞：编制上限 80%，安全下限 50%。
- 上限限制自动补员和正常的现有士兵移交；下限只限制从驻军抽调。
- 统一驻军人数为驻军实际名册人数加所有活跃征粮队的当前成员数。征粮队离城后仍占原驻地编制，返城时不会再次获得一份容量。
- 硬上限始终由本体驻军 PartySizeLimit 决定。

## 实现入口

- `GarrisonRecruitmentCapacity` 是驻军人数、上下限和剩余容量的单一入口。
- `GarrisonTransferPolicyModel.IsEnemyBorderFortification` 继续负责边境判定。
- `RecruitmentAdmissionModel` 对新兵和场军移交使用同一上限目标。
- `GarrisonDefenseRequirementModel` 使用统一驻军人数与下限计算安全调出数量。
- Harmony Patch 只读取模型或调用服务，不复制比例规则。

## 配置

`militaryConfig.xml` 的 `ForceManagement` 节点提供四个比例：

```xml
<InteriorGarrisonUpperRatio value="0.80"/>
<BorderGarrisonUpperRatio value="0.95"/>
<InteriorGarrisonLowerRatio value="0.50"/>
<BorderGarrisonLowerRatio value="0.75"/>
```

配置加载会拒绝下限高于上限的组合。自动换兵和跨城增援仍保持关闭。
