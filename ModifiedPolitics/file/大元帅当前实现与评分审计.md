## 2. 当前任职资格

候选人必须：

- 存活、活跃且未被俘；
- 所属 Clan 仍属于目标王国；
- 所属 Clan 未灭亡且不是雇佣兵 Clan；
- 不是王国统治者；
- 没有担任 Governor；
- 可以领军；
- 当前领导一支活跃的 Lord Party；
- 未担任其他官职；
- 所属 Clan 尚未占有其他大元帅席位。

当前大元帅席位上限为 3，并要求三名大元帅来自不同 Clan。王国统治者不占用大元帅席位，但在亲自领军时拥有同等军团创建权限。

## 3. 统一评分 Model

评分集中在 `MarshalAppointmentScoreModel`，对外提供：

```text
Evaluate(Hero, Kingdom) -> MarshalAppointmentScore
GetScore(Hero, Kingdom) -> FinalScore
GetAbilityScore(Hero) -> AbilityScore
GetTraitScore(Hero) -> TraitScore
ShouldReplace(incumbent, challenger, Kingdom) -> bool
```

资格仍由 `OfficeRules` 判断，Model 只负责排序与复核标准。

评分权重、影响力目标和职位数量从 `ModuleData/hero_offices.xml` 的文化节点下读取：

```xml
<MarshalScore
    officeLimit="3"
    influenceTarget="1000"
    politicalPriorityBand="1000000"
    relationBand="1000"
    armyReadyBonus="500"
    lowInfluenceBonus="400"
    clanTierWeight="10"
    officeDistributionBonus="50"
    competenceTieBreakerMax="9.9"
    competenceDivisor="500"
    tacticsWeight="3"
    leadershipWeight="3"
    scoutingWeight="2"
    stewardWeight="2"
    engineeringWeight="2"
    charmWeight="1"
    tradeWeight="1"
    calculatingWeight="50"
    valorWeight="40"
    honorWeight="30" />
```

缺少 `MarshalScore` 子节点时使用相同默认值，旧 XML 不会导致读取失败。

### 3.1 严格排序层级

最终分使用分数区间保证上层因素不会被下层能力反超：

1. 统治家族 Hero 优先；
2. 玩家 Hero 获得独立优先级，方便玩家取得军团征召权；
3. 其余 Hero 按候选 Clan 领袖与统治者的关系排序；
4. 当前影响力能够覆盖动态军团目标者优先；
5. 在能够创建军团的前提下，优先扶持影响力较低的 Clan；
6. 适度考虑 Clan Tier；
7. 优先让当前官职较少的 Clan 获得机会；
8. 军事能力与性格只作为最后的同政治条件择优项。

玩家便利不再通过“能力分 ×10”伪装成军事才能，而是作为明确的政治优先级记录在评分明细中。

### 3.2 能力分

```text
Tactics × 3
+ Leadership × 3
+ Scouting × 2
+ Steward × 2
+ Engineering × 2
+ Charm
+ Trade
```

### 3.3 性格分

```text
Calculating 等级 × 50
+ Valor 等级 × 40
+ Honor 等级 × 30
```

负 Trait 等级会产生负分，但能力与性格只参与最终的末级择优。

### 3.4 动态军团影响力目标

Model 枚举该王国当前活跃、未加入其他 Army、未解散的 Lord Party，并使用原版 `CalculatePartyInfluenceCost` 计算候选大元帅召集各部队的实际影响力成本。由于大元帅上任后享受 25% 召集优惠，目标按折后成本累计。

最终目标：

```text
RequiredInfluence = min(XML influenceTarget, max(50, 可召集部队折后成本总和))
```

默认 `influenceTarget=1000`。地图上可召集部队较少时目标会低于 1000；可召集部队很多时最多按 1000 评价。UI 和日志显示 `当前影响力/动态目标影响力`。

## 4. 各调用路径差异

| 场景 | 使用的分数 |
|---|---|
| 普通文化系统候选排序 | 统一最终分 |
| 瓦兰迪亚前三候选排序 | 统一最终分；仍先保证每 Clan 最多一名候选 |
| 决议 Merit | 统一最终分 |
| Clan 投票支持度 | 统一最终分 ÷ 20，再加入该投票 Clan 的个人关系 |
| 玩家或 AI 申请的统治者接受判断 | 统一最终分 |
| 每 28 日现任复核 | `ShouldReplace` 稳定复核规则 |

### 4.1 定期复核稳定规则

复核不会直接对带有巨大政治区间的最终分做 125% 乘法。按以下顺序判断：

- 政治优先级更高时允许替换；
- 与统治者关系至少高 10 时允许替换，低 10 时拒绝替换；
- 前者无法维持军团、后者达到 50 影响力时允许替换；
- 低影响力扶持分至少改善 100 时允许替换；
- 上述政治条件相近时，能力与性格合计至少达到现任的 125% 才允许替换。
