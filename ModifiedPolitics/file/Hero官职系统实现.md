# Hero 官职系统实现

## 模块位置

代码位于：

`ModifiedPolitics/ModifiedPolitics/HeroOffices`

文化配置位于：

`ModifiedPolitics/ModifiedPolitics/ModuleData/hero_offices.xml`

## 已实现的基础能力

- 任职记录存档与读档；
- 一名 Hero 同时只能拥有一个官职；
- 按 `Kingdom.Culture` 读取可用官职和地方席位配置；
- 按城镇或城堡数量计算地方官职席位；
- Hero 被俘、死亡、Clan 离开王国、王国灭亡或失去 Governor 资格时自动失效；
- 领土减少造成超额时，保留评分最高者；
- 中央官职每日影响力 +5，地方官职每日影响力 +1；
- 普通官职的统治者任命、关系奖励、撤职关系损失与固定补偿；
- 税务长官、农业长官和治安长官的定居点效果；
- 首席大臣对地方官职本身效果的 10% 强化；
- 大元帅的军团创建权限、召集消耗和维持消耗修正；
- 大元帅失效时解散其领导的 Army；
- 大元帅任命和撤职使用本体王国决议平台；
- 帝国、阿塞莱和库赛特的其他 Clan 弃权，瓦兰迪亚和斯特吉亚正常投票；
- 瓦兰迪亚按每 Clan 一名最佳候选人选出全国前三，其他文化由统治者提名；
- AI 每 28 天复核大元帅，只有新候选评分达到现任的 125% 时才发起撤职决议；
- 宫廷总管使王国政治投票产生的负面关系变化减少 25%；
- 正规兵源和驻军招募增速的稳定查询 API。
- 军事长官对 `ModifiedArmy` 正规兵源生成和每日驻军招募上限的实际接入。
- 地方官职空缺时的 AI 即时补缺；
- 地方官职每 28 天复核、25% 换人门槛、关系考量和财政补偿选择。
